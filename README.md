# Рапортичка — Backend

REST API учёта посещаемости занятий для учебного заведения (колледжа). Система рассчитана
на все учебные группы: каждая группа ведёт собственные рапортички, за каждой закреплены
куратор и преподаватели-предметники, а расписание пар загружается из АИС КТК для любой
группы колледжа — не только для одной.

## Возможности

- Роли и права:
  - **Староста** — ведёт рапортички только для **своей группы** и **только за текущий день**: создаёт сессии, отмечает посещаемость, загружает `.docx` со списком группы, пополняет каталог предметов.
  - **Преподаватель-куратор** — видит свою группу целиком: все сессии, подтверждает/отклоняет, выгружает рапортички за период.
  - **Преподаватель-предметник** — видит только пары тех предметов, которые закреплены за ним.
  - **Администратор** — управляет всеми группами (назначение кураторов), преподавателями, студентами, каталогом предметов; видит подключённые устройства и ошибки приложений; задаёт адрес сервера и параметры Wi-Fi, управляет туннелем и рассылает новый адрес устройствам.
- Интеграция с расписанием КТК:
  - Прокси к API колледжа (отделения, курсы, группы, преподаватели).
  - Загрузка недельного расписания **для любой группы** с автосозданием недостающих предметов в каталоге.
  - Сопоставление преподавателей по ФИО (краткая форма из расписания) и привязка их к предметам.
  - Шаблон недели хранится на сервере и правится: добавить/изменить/отменить/удалить пару.
  - Создание рапортички **по расписанию**: для даты формируются сессии по всем парам шаблона; режимы `missing` (дописать недостающие) и `resync` (дописать и удалить лишние неподтверждённые).
- Глобальный каталог **предметов** (`subjects`) с закреплением преподавателя.
- Экспорт рапортички: **PDF / DOCX / XLSX** (несколько пар одного дня объединяются в один лист).
- Загрузка и разбор образца рапортички `.docx` (замена группы и списка студентов).
- Телеметрия: регистрация устройств (`/analytics/device`), сбор ошибок приложений (`/analytics/error`).
- Push-конфиг: устройства опрашивают сервер (`/push/config`); при изменении версии получают новый адрес сервера и параметры Wi-Fi.
- Туннель: ngrok / cloudflared для доступа без локальной сети.
- JWT-аутентификация, CORS.

## Технологии

- Python 3.12+ · FastAPI · Uvicorn
- SQLAlchemy 2.0 · PostgreSQL · psycopg2
- passlib/bcrypt + python-jose (пароли и JWT)
- python-docx, fpdf2, openpyxl (экспорт), python-multipart (загрузка файлов)

## Требования

- Python 3.12+
- PostgreSQL (локально или удалённо)
- Доступ к `http://mob.kansk-tc.ru/ktc-api` для загрузки расписания

## Установка и запуск

```bash
# 1. Создать базу данных
createdb raport   # имя можно любое, см. DATABASE_URL

# 2. Виртуальное окружение и зависимости
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Указать строку подключения (иначе будет postgresql://localhost:5432/raport)
export DATABASE_URL="postgresql://user:password@localhost:5432/raport"

# 4. Запуск API
uvicorn main:app --host 0.0.0.0 --port 8010
```

Swagger-документация: http://localhost:8010/docs · проверка: `http://localhost:8010/health` → `{"status":"ok"}`

## Сидирование базы

```bash
python seed.py [путь_к_рапортичке.docx | ТЕСТ.00.00.1]
```

- Без аргумента создаётся **демо-группа** «ТЕСТ.00.00.1» с 12 тестовыми студентами и каталогом из 6 предметов.
- С аргументом-файлом группы и студенты разбираются из образца рапортички `.docx`.

Учётные записи создаёт администратор через админ-панель; в тестовой среде их задаёт
`seed.py` (логины/пароли назначаются разработчиком).

## API

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/auth/login` | Вход, JWT-токен и данные пользователя |
| GET  | `/groups` · `/groups/{id}` | Группы пользователя / детали группы |
| GET  | `/students?group_id=` · POST · PUT · DELETE `/students/{id}` | Студенты группы (CRUD) |
| GET  | `/subjects` · POST · PATCH · DELETE | Каталог предметов (привязка преподавателя) |
| GET  | `/sessions?group_id=` | Сессии группы (фильтры по дате/подтверждению) |
| POST | `/sessions` | Создать сессию (староста: своя группа + сегодня) |
| PUT  | `/sessions/{id}` · `/records` | Обновить сессию / отметить студентов |
| POST | `/sessions/{id}/confirm` · `/unconfirm` | Подтвердить / снять подтверждение |
| GET  | `/export/session/{id}?fmt=pdf\|docx\|xlsx` | Выгрузка одной сессии |
| GET  | `/export/group/{id}?date_from=&date_to=&fmt=` | Выгрузка за период (день объединяется в лист) |
| POST | `/upload/raport` · `/apply` | Разбор `.docx` со списком группы / применение |
| GET  | `/ktc/branches` · `/ktc/courses/{id}` · `/ktc/teachers/{id}` | Прокси к API КТК |
| GET  | `/schedule/{group_id}` | Шаблон недели группы |
| PUT  | `/schedule/{group_id}/source` | Привязать источник КТК (отделение, группа) |
| POST | `/schedule/{group_id}/import` | Загрузить расписание недели из КТК |
| POST | `/schedule/{group_id}/entries` · PATCH/DELETE `/schedule/{id}` | Правка пары шаблона |
| POST | `/schedule/{group_id}/create-sessions` | Создать рапортичку по расписанию (`missing`/`resync`) |
| POST | `/analytics/device` · `/analytics/error` | Телеметрия |
| GET  | `/admin/teachers` · `/admin/groups` · `/admin/students` | Админ: CRUD преподавателей/групп |
| GET  | `/admin/devices` · `/admin/errors` (DELETE) | Админ: устройства и ошибки |
| GET/POST | `/admin/config` | Админ: адрес сервера, Wi-Fi |
| GET/POST | `/admin/tunnel/status` · `/start` · `/stop` · `/send-url` | Админ: туннель |

## Тесты

```bash
python seed.py
python tests/setup_teacher2.py   # преподаватель-предметник для проверки прав
python tests/test_api.py
```

`tests/test_api.py` прогоняет сценарии прав доступа, создание сессий, подтверждение,
экспорт, админ-раздела и расписания (импорт КТК, правка шаблона, «создать по расписанию»).

## Структура

```
backend/
├── main.py            # точка входа FastAPI
├── auth.py            # JWT, пароли, проверки ролей
├── database.py        # движок SQLAlchemy, DATABASE_URL
├── models.py          # ORM-модели
├── schemas.py         # Pydantic-схемы
├── seed.py            # сидирование базы
├── routes/            # auth, groups, students, subjects, sessions, export,
│                      # upload, admin, analytics, push, ktc, schedule
├── services/          # exporter (pdf/docx/xlsx), docx_parser, visibility,
│                      # ktc (клиент АИС), schedule_import, tunnel
└── tests/             # e2e-тесты API
```
