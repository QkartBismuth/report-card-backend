# Рапортичка — Backend

REST API для учёта посещаемости занятий учебной группы («ТЕСТ.00.00.1»). Приложение позволяет старосте вести ежедневные рапортички, а преподавателям подтверждать их и выгружать в файлы Word / Excel / PDF.

## Возможности

- Роли и права:
  - **Староста** — ведёт рапортички только для **своей группы** и **только за текущий день**: создаёт сессии, отмечает посещаемость, загружает `.docx` со списком группы, пополняет каталог предметов.
  - **Преподаватель-куратор** — видит свою группу целиком: все сессии, подтверждает/отклоняет, выгружает рапортички за период.
  - **Преподаватель-предметник** — видит только пары тех предметов, которые закреплены за ним.
- Глобальный каталог **предметов** (`subjects`) с закреплением преподавателя.
- Экспорт рапортички: **PDF / DOCX / XLSX** (несколько пар одного дня объединяются в один лист).
- Загрузка и разбор образца рапортички `.docx` (замена группы и списка студентов).
- JWT-аутентификация, CORS.

## Технологии

- Python 3.12+ · FastAPI · Uvicorn
- SQLAlchemy 2.0 · PostgreSQL · psycopg2
- passlib/bcrypt + python-jose (пароли и JWT)
- python-docx, fpdf2, openpyxl (экспорт), python-multipart (загрузка файлов)

## Требования

- Python 3.12+
- PostgreSQL (локально или удалённо)

## Установка и запуск

```bash
# 1. Создать базу данных
createdb raport   # имя можно любое, см. DATABASE_URL

# 2. Виртуальное окружение и зависимости
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Указать строку подключения (иначе будет postgresql://localhost:5432/raport)
export DATABASE_URL="postgresql://user:password@localhost:5432/raport"

# 4. Запуск API
uvicorn main:app --host 0.0.0.0 --port 8010
```

Swagger-документация: http://localhost:8010/docs · проверка: `http://localhost:8010/health` → `{"status":"ok"}`

## Сидирование базы

```bash
python seed.py [путь_к_рапортичке.docx | ТЕСТ.00.00.1]
```

- Без аргумента создаётся **демо-группа** «ТЕСТ.00.00.1» с 12 тестовыми студентами и каталогом из 6 предметов (все закреплены за преподавателем).
- С аргументом-файлом группы и студенты разбираются из образца рапортички `.docx`.

Пользователи по умолчанию:

| Логин     | Пароль       | Роль         |
|-----------|--------------|--------------|
| `starosta` | `starosta123` | староста     |
| `teacher`  | `teacher123`  | преподаватель |

## API

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/auth/login` | Вход, JWT-токен и данные пользователя |
| GET  | `/groups` | Группы пользователя (куратор — своя, староста — своя) |
| GET  | `/groups/{id}` | Детали группы |
| GET  | `/students?group_id=` | Студенты группы |
| POST | `/students?group_id=` | Добавить студента |
| DELETE | `/students/{id}` | Удалить студента |
| GET  | `/subjects` | Каталог предметов (предметник — только свои) |
| POST | `/subjects` | Добавить предмет (преподаватель закрепляет его за собой) |
| PATCH | `/subjects/{id}` | Назначить преподавателя предмету |
| DELETE | `/subjects/{id}` | Удалить предмет (только преподаватель) |
| GET  | `/sessions?group_id=` | Сессии группы (с фильтрами по датам/подтверждению) |
| GET  | `/sessions/{id}` | Сессия со списком отметок |
| POST | `/sessions` | Создать сессию (староста: своя группа + сегодня) |
| PUT  | `/sessions/{id}` | Обновить сессию |
| PUT  | `/sessions/{id}/records` | Отметить студентов (староста) |
| POST | `/sessions/{id}/confirm` | Подтвердить сессию (преподаватель) |
| POST | `/sessions/{id}/unconfirm` | Снять подтверждение |
| GET  | `/export/session/{id}?fmt=pdf\|docx\|xlsx` | Выгрузка одной сессии |
| GET  | `/export/group/{id}?date_from=&date_to=&fmt=` | Выгрузка за период (пары дня объединяются в лист) |
| POST | `/upload/raport` | Разобрать `.docx` со списком группы |
| POST | `/upload/raport/apply` | Применить список (создать/заменить группу) |

## Тесты

```bash
python seed.py
python tests/setup_teacher2.py   # создаёт преподавателя-предметника для проверки прав
python tests/test_api.py
```

`tests/test_api.py` прогоняет сценарии прав доступа, создание сессий, подтверждение и экспорт. Тест загрузки `.docx` пропускается, если рядом нет образца рапортички.

## Структура

```

├── main.py           # точка входа FastAPI
├── auth.py           # JWT, пароли, проверки ролей

├── models.py         # ORM-модели
├── schemas.py        # Pydantic-схемы
├── seed.py           # сидирование базы
├── routes/           # auth, groups, students, subjects, sessions, export, upload
├── services/         # exporter (pdf/docx/xlsx), docx_parser, visibility
└── tests/            # e2e-тесты API
```
